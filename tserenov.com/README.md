# tserenov.com

Локальный прототип личного сайта Церена Церенова. Согласованные решения, оценки полного проекта и этапы хранятся в карточке РП442, фаза Ф16. Этот документ описывает реализацию и проверку прототипа.

## Запуск

Требуется Zola **0.23.6**. Это генератор на Rust; сервер приложений и база данных не нужны. Версия проверена при сборке 06.10.2026. В 0.23 используются компоненты Tera вместо старых shortcodes.

```sh
zola build
python3 scripts/verify.py
zola serve --interface 127.0.0.1 --port 4420
```

В текущей сессии бинарник Zola находится в `/private/tmp/wp442-zola/zola` (официальный release getzola/zola, сверена опубликованная SHA-256). Папка временная; для последующих запусков нужен установленный Zola или повторное получение официального выпуска. В исходники бинарник не включён.

Адреса:

- русский: `http://127.0.0.1:4420/`;
- английский: `http://127.0.0.1:4420/en/`;
- калмыцкая редакция: `http://127.0.0.1:4420/xal/`.

## Три редакции

`data/editorial.json` хранит отдельные подборки, навигацию и социальные ссылки. Страницы в `content/` содержат Markdown и метаданные. Суффиксы `.en.md` и `.xal.md` задают язык. Имена связанных страниц позволяют Zola найти эквивалентную редакцию; если её нет, переключатель ведёт на главную выбранного языка с соответствующей подписью.

Русская редакция: биография, манифест, публичное представление Lifework, видео и действующие ссылки на Telegram, YouTube, TenChat и клуб.

Английская: самостоятельная главная, адаптации биографии и Lifework, сокращённая адаптация манифеста; тексты пока требуют авторской редактуры. Русские социальные каналы не переносятся автоматически.

Калмыцкая: отдельная главная и пустая библиотека. Служебное описание размечено `lang="ru"`; литературного перевода ещё нет. `ready: false` означает, что нет утверждённой подборки. До носительской проверки не выдавать эту страницу за переведённый сайт.

## Управление из IWE

Сейчас реализован первый шаг: локальное редактирование выбранных Markdown/JSON и автоматическое обновление предпросмотра Zola. Полный конвейер публикации, снятие материалов с сайта, браузерная панель и загрузка видео в сервисы пока не реализованы.

Планируемая модель: материал и редакция имеют независимые состояния `draft → review → approved → published`, а связь переводов хранится отдельно от решения о публикации. Подключение существующего публикатора требует отдельной реализации и проверки; этот прототип его не вызывает и не меняет статусы оригиналов.

В прототипе фильтр библиотеки ищет по названиям и описаниям только текущей редакции. Полнотекстовый Pagefind остаётся этапом наполнения, не выдаётся за выполненный.

## Граница публикации

По умолчанию `extra.preview = true`, все собственные страницы содержат `noindex, nofollow`, а `robots.txt` закрывает обход. Это настройки предпросмотра, не парольная защита. Сервер слушает только localhost; внешнее размещение не выполнено.

Перед публичным запуском нужны: утверждение текстов и состава материалов по языкам; проверка калмыцкого; настоящий `base_url`; готовый механизм выбора только утверждённых страниц; корректные правила индексации; проверка хостинга и DNS/почты. Простое переключение `preview=false` НЕ делает материалы утверждёнными. Встроенного боевого публикационного гейта пока нет.

## Проверки

`zola build` проверяет шаблоны и внутренние ссылки Markdown. `scripts/verify.py` проверяет готовые страницы, внутренние ссылки/якоря, наличие трёх редакций и меток предпросмотра. Браузерная проверка дополнительно охватывает ширину экрана, переключатель языков, фильтрацию библиотеки и создание видеоплеера по действию читателя.

Автоматического деплоя, секретов и конфигурации домена в проекте нет. Исходная папка мастерской предназначена для прототипа; постоянный дом исполняемого инструмента уточняется при реализации публикационного конвейера.

Результат 06.10.2026: сборка и проверка 13 страниц успешны; браузер — 39 сочетаний страниц и ширин 320/390/1440, увеличение текста главной до 200%, работа фильтра, переход к английской адаптации, переход к главной при отсутствии перевода, отсутствие русских социальных каналов в EN, создание плеера по нажатию. Ошибок JavaScript и горизонтального переполнения нет. Воспроизведение видео у YouTube не проверялось: ответ iframe перехвачен тестом; отдельно проверены исходный URL и oEmbed. Снимки и детальный браузерный результат текущего прогона находятся в `/private/tmp/wp442-*-desktop.png`, `/private/tmp/wp442-ru-mobile.png`, `/private/tmp/wp442-browser-report.json` и не являются долговременным хранилищем.
