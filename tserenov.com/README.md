# tserenov.com

Локальный прототип личного сайта Церена Церенова. Согласованные решения, оценки полного проекта и этапы хранятся в карточке РП442, фаза Ф16. Этот документ описывает реализацию и проверку прототипа.

## Запуск

Требуется Zola **0.23.6**. Это генератор на Rust; сервер приложений и база данных не нужны. Версия проверена при сборке 06.10.2026. В 0.23 используются компоненты Tera вместо старых shortcodes.

```sh
zola build
python3 scripts/verify.py
zola serve --interface 127.0.0.1 --port 4420
```

Для текущей проверки использован официальный Zola 0.23.6. В исходники бинарник не включён; локально можно передать его путь через `ZOLA_BIN`.

Адреса:

- русский: `http://127.0.0.1:4420/`;
- английский: `http://127.0.0.1:4420/en/`;
- калмыцкая редакция: `http://127.0.0.1:4420/xal/`.

## Три редакции

`data/editorial.json` хранит отдельные подборки, навигацию и социальные ссылки. Страницы в `content/` содержат Markdown и метаданные. Суффиксы `.en.md` и `.xal.md` задают язык. Имена связанных страниц позволяют Zola найти эквивалентную редакцию; если её нет, переключатель ведёт на главную выбранного языка с соответствующей подписью.

Русская редакция: биография, манифест, публичное представление Lifework, видео, 12 лонгридов и действующие ссылки на Telegram, YouTube, TenChat и клуб.

Английская: самостоятельная главная, адаптации биографии и Lifework, сокращённая адаптация манифеста; тексты пока требуют авторской редактуры. Русские социальные каналы не переносятся автоматически.

Калмыцкая: отдельная главная и пустая библиотека. Служебное описание размечено `lang="ru"`; литературного перевода ещё нет. `ready: false` означает, что нет утверждённой подборки. До носительской проверки не выдавать эту страницу за переведённый сайт.

## Управление из IWE

Сейчас реализован первый шаг: локальное редактирование выбранных Markdown/JSON и автоматическое обновление предпросмотра Zola. Полный конвейер публикации, снятие материалов с сайта, браузерная панель и загрузка видео в сервисы пока не реализованы.

Планируемая модель: материал и редакция имеют независимые состояния `draft → review → approved → published`, а связь переводов хранится отдельно от решения о публикации. Подключение существующего публикатора требует отдельной реализации и проверки; этот прототип его не вызывает и не меняет статусы оригиналов.

В прототипе фильтр библиотеки ищет по названиям и описаниям только текущей редакции. Полнотекстовый Pagefind остаётся этапом наполнения, не выдаётся за выполненный.

## Граница публикации

По умолчанию `extra.preview = true`, все собственные страницы содержат `noindex, nofollow`, а `robots.txt` закрывает обход. Это настройки локального предпросмотра, не парольная защита. Его сервер слушает только localhost. Для внешнего размещения используется отдельная сборка `public-release/`.

Для первого публичного запуска выбраны русская и английская редакции. Калмыцкая остаётся только в локальном предпросмотре до проверки носителем. Почта `@tserenov.com` не используется. Регистрация домена перенесена в Namecheap, DNS обслуживает Cloudflare; корневая CNAME-запись направляет сайт на `tserenov-com.pages.dev`.

## Сборка для первого запуска

`python3 scripts/release.py` создаёт `public-release/` только после двух проверок: у каждой русской и английской редакции стоит явное `publication_approved: true` в `data/editorial.json`, а у каждой публикуемой страницы — `editorial_status = "approved"` или `"published"`. Владелец разрешил запуск RU/EN 14.10.2026; 19 материалов получили статус `approved` без изменения основного текста. Флаг `ready` обозначает готовность редакции к предпросмотру и не заменяет разрешение на публикацию.

Разрешённая сборка использует `https://tserenov.com` для адресов страниц, убирает калмыцкие маршруты и ссылки, открывает индексацию в `robots.txt` и проверяет страницы, карту сайта и внутренние ссылки. Исходный локальный предпросмотр остаётся отдельным. На публичной странице RU/EN есть форма вопроса: сервер ищет в открытом MCP и возвращает ссылки на источники. Платная генерация выключена до установки отдельного ключа и положительного лимита расходов.

Первое размещение использует Cloudflare Pages с прямой загрузкой проверенной папки `public-release/` в проект `tserenov-com`; исходники остаются в `DS-Tseren-Brand`. Для обновления повторить сборку и выполнить `wrangler pages deploy public-release --project-name tserenov-com --branch main` из этой папки. Прямую загрузку нужно повторять после изменений исходников: один лишь push в GitHub сайт не обновляет. Подключение Git-провайдера и автоматическая доставка остаются отдельной задачей. Адреса сборок Pages публичны по умолчанию; загружать можно только утверждённую сборку.

14.10.2026 проверенная сборка размещена в Cloudflare Pages (публикация исходников `3a650b8`). Основной адрес — `https://tserenov.com/`, английская редакция — `https://tserenov.com/en/`; оба адреса внешне проверены по HTTPS и вернули 200, сертификат для домена действителен. Адрес `https://tserenov-com.pages.dev/` остаётся техническим адресом той же сборки. В авторитетном DNS Cloudflare появилась корневая запись сайта; повторная проверка Pages завершилась статусом `active` для домена и сертификата. Первые обновления размещаются прямой загрузкой, как указано выше.

## Проверки

`zola build` проверяет шаблоны и внутренние ссылки Markdown. `scripts/verify.py` проверяет готовые страницы, внутренние ссылки/якоря, наличие трёх редакций и меток предпросмотра. Браузерная проверка дополнительно охватывает ширину экрана, переключатель языков, фильтрацию библиотеки и создание видеоплеера по действию читателя.

Автоматического деплоя и секретов в исходниках нет. Публичный Pages-проект создан отдельно; исходная папка мастерской остаётся местом подготовки материалов. Конвейер автоматического обновления сайта из IWE ещё не реализован.

Результат 06.10.2026: сборка и проверка 13 страниц успешны; браузер — 39 сочетаний страниц и ширин 320/390/1440, увеличение текста главной до 200%, работа фильтра, переход к английской адаптации, переход к главной при отсутствии перевода, отсутствие русских социальных каналов в EN, создание плеера по нажатию. Ошибок JavaScript и горизонтального переполнения нет. Воспроизведение видео у YouTube не проверялось: ответ iframe перехвачен тестом; отдельно проверены исходный URL и oEmbed. Снимки и детальный браузерный результат текущего прогона находятся в `/private/tmp/wp442-*-desktop.png`, `/private/tmp/wp442-ru-mobile.png`, `/private/tmp/wp442-browser-report.json` и не являются долговременным хранилищем.

## Блок вопроса и онбординг — РП590, 06.10.2026

Главные RU/EN содержат `#ask`: поле вопроса, три примера, ссылки на материалы и раскрывающиеся шаги знакомства. В XAL нет неподтверждённых переводов интерфейса. Кнопки активируются JavaScript только после установки локальных обработчиков. Без JavaScript форма остаётся недоступна для отправки. Вопрос уходит на Pages Function `/api/ask`, затем в публичный MCP; браузер не хранит ключ модели. Числовая квота не показывается до настройки бюджета.

Рабочий MCP с онбордингом и авторской подборкой относится к РП590, а интерфейс сайта — к РП442. РП581 не является обязательной зависимостью. Полный проект лимитов, оплаты и приёмки записан в карточке РП590, раздел «Публичный помощник на tserenov.com — поручение 06.10.2026».

Локальный проход 08.10.2026: при открытии собранного сайта через `mcp.tserenov.com` на `http://127.0.0.1:4420/` форма отправляет вопрос в локальный `/api/ask` и показывает материалы выбранного открытого репозитория, кроме черновиков, со ссылками на закреплённую ревизию источника. ИИ-модель не вызывается; на внешнем адресе форма сохраняет состояние неподключённого сервиса. Инструкция запуска — в `mcp.tserenov.com/README.md`. Это проверка взаимодействия сайта и MCP, а не разрешение на публичный запуск.

Публичный экземпляр РП590 и серверный поиск теперь реализованы. Код платного маршрута использует отдельный OpenAI API, только после установки `OPENAI_API_KEY`, `ASK_HASH_SALT` и положительного `AI_MONTHLY_LIMIT_CENTS`. Нулевой предел в `wrangler.toml` сохраняет генерацию выключенной. Для оплаты D1 атомарно резервирует верхнюю оценку стоимости каждого вызова и ведёт общий месячный счётчик; посетитель ограничен десятью вызовами за день по солёному хешу IP. При отсутствии источников модель не вызывается. До включения платного маршрута нужны согласованный бюджет, собственный API-ключ владельца и проверка реальных ответов/расходов на RU/EN. История локального предпросмотра выше сохранена как свидетельство предыдущего этапа.

Предпочтение автора — OpenCode Go. Однако документация https://opencode.ai/docs/go/ ориентирует Go на coding-agent traffic, а https://opencode.ai/legal/terms-of-service ограничивает использование внутренними задачами, не обслуживанием третьих лиц (проверено 06.10.2026). Публичный помощник через обычную Go не считается разрешённым до отдельного подтверждения поставщика. Нет ключей, запросов к модели, расходов или изменений оплаты. Самостоятельный выбор другого платного провайдера не произведён.

Проверка блока 06.10.2026: 6 сочетаний RU/EN и ширин 320/390/1440; примеры заполняют поле, отправка показывает честное неподключённое состояние, онбординг раскрывается; после действий пользователя сетевых запросов нет. Без JavaScript отправка отключена. Общие проверки 13 страниц и 39 сочетаний ширин также прошли. Это проверка интерфейса, не живого ИИ, MCP или квот.

Предлагаемая числовая квота убрана из пользовательского интерфейса, остаётся в РП590 как проект. Адрес MCP, рабочий API, ответы и остаток квоты не выдумываются.
