# 2.2. Рабочее сообщение команде

## Переписка с разработчиками

В рабочей группе разработки за семь дат с 7 марта по 31 декабря 2024 года найдены 17 исходящих текстов с аккаунта автора. После исключения одной пересылки осталось 16 сообщений общим объёмом 484 слова. Ссылки и упоминания аккаунтов исключены из числа слов. Из двух совпадающих выгрузок использована одна.

| Показатель | Замер |
|---|---:|
| Длина сообщения, медиана | 23 слова |
| Нижний и верхний квартили длины | 13,5 и 37,75 слова |
| Минимум и максимум | 3 и 79 слов |
| Сообщения со знаком вопроса | 4 из 16 |
| Ответы с явной привязкой к другому сообщению | 10 из 16 |
| Сообщения с пустой строкой между абзацами | 2 из 16 |

В девяти из десяти явных ответов автор отвечал другому собеседнику. Одна дата дала восемь из шестнадцати наблюдений. Эти числа пригодны как первый ориентир для короткого рабочего диалога. Для объявления всей команде нужно отдельно подобрать тексты, где автор явно обращается к группе. Общие черты голоса описаны в [профиле автора](0-voice.md).

## Переписка в методсовете

В рабочей группе методсовета в корпус вошло 241 сообщение с аккаунта автора за 151 день с 19 января 2022 года по 31 декабря 2024 года. Из отбора исключены пересылки, сообщения с вложениями, сообщения с признаками цитирования, копии чужого текста и сообщения без слов. При выборе образца проверяющий дополнительно устанавливает происхождение текста.

| Показатель | Замер |
|---|---:|
| Объём переписки | 9 698 слов |
| Длина сообщения, медиана | 22 слова |
| Нижний и верхний квартили длины | 10 и 47 слов |
| Сообщения со знаком вопроса | 33 из 241 |
| Ответы с явной привязкой к другому сообщению | 137 из 241 |
| Из этих ответов адресованы другому участнику | 131 |

Для ручного отбора отмечены 25 сообщений на 23 датах в 2022–2023 годах. В 21 случае сохранена привязка к сообщению собеседника. При выборе примера важно отметить, отвечает ли автор одному коллеге, координирует ли несколько человек или обращается ко всей группе. У методсовета свои задачи и правила отбора корпуса, поэтому показатели двух групп приведены отдельно.
