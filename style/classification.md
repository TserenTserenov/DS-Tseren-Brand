# Классификация стилей автора

Каждый текст автора задаётся тремя осями: общий голос, канал и отношение к читателю. Номер стиля («2.1») — его имя, так его называют в разговоре. Машинные идентификаторы живут в реестре стилей (PACK-rhetoric), здесь только ссылка на них. Поле (о чём текст: ИИ, обучение, бизнес) стили не делит.

## Ось 3. Отношение к читателю

Буквенные коды. Сегменты карты целевых аудиторий (A1, A2, K, C …, файл «Целевые аудитории 1.1» в DS-ecosystem-development) — частный случай отношения «публика».

| Код | Отношение | Состояние |
|---|---|---|
| НЕ ЗАПОЛНЕНО | Коды отношения не назначены | автор назначает коды; кандидаты по первой волне: команда, участники практикума, подписчики |

## Как читать комбинацию

Пример: «2.1 · C» означает пост для тёплой базы. Голос 0 общий для всех комбинаций; канал задаёт форму (длину, разметку, ритм); отношение задаёт тон и словарь.
